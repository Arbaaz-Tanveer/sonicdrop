How does it work?

OFDM modem

Data rides on 629 tones between 1.1 and 15.8 kHz. Each one carries BPSK up to 16-QAM, with pilot tones that track clock drift between the two devices.

LDPC error correction

Modern capacity-approaching codes (the same family Wi-Fi and 5G use) recover data even when many tones are buried by echoes and noise.

Fountain coding

The sender streams an endless supply of coded packets. Any set equal to the file size rebuilds it, so the receiver can join late and lost bits never need a resend.

Private by design

Nothing touches a server. Optional AES-256-GCM encryption with a passphrase, and a SHA-256 check proves the received file is bit-exact.
